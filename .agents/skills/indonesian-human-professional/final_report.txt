## Scope Boundary

> [!IMPORTANT]
> This skill covers the **language layer** only.

| In scope (this skill) | Out of scope (other skills) |
|---|---|
| Word correctness (baku/tidak-baku) | Paper structure (Bab I-V ordering) |
| EYD V spelling rules | Typst template formatting |
| Anti-AI writing patterns | Page margins, fonts, headings |
| Pasif Persona, rhythm, diction | Bibliography rendering |
| Academic compliance (Bloom's verbs, APA 7th localized, AI disclosure) | Compilation (`typst compile`) |
| Foreign word detection | Figure/table numbering |

Paper structure and Typst formatting are handled by `typst-paper`. Both skills compose naturally when writing Indonesian academic papers — they trigger independently based on context.

## 8-Layer Pipeline

| Layer | Domain | Tool | Input → Output |
|---|---|---|---|
| L1 | `bahasa-core` | lantip JSON | Word → corrected word |
| L2 | `bahasa-core` | PySastrawi | Word → root word |
| L3 | `bahasa-core` | KBBI dataset | Root → baku/tidak-baku |
| L4 | `bahasa-core` | Stanza POS + gipsterya rules | Token → di-spacing verdict |
| L6 | `anti-ai-style` | banned_phrases.json + Stanza | Sentence → flagged phrases |
| L7 | `anti-ai-style` | Stanza + word count | Paragraph → variance score |
| L8 | `anti-ai-style` | Stanza POS + pattern | Sentence → passive type |
| L9 | `bahasa-core` | Inverse KBBI check | Word → foreign/native tag |

### Layer Dependencies

```
Group A (word-level, parallel): L1, L2→L3, L2→L9
Group B (sentence-level, parallel): L4, L6, L7, L8
L8 also depends on L2 (needs verb root)
Groups A and B run concurrently after Stanza init
```
